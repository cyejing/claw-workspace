# Value Investor Tracker

监控价值投资人持仓变化，数据源整合：
- **SEC 13F**：直接拉取**最近两期**官方申报自动 diff，得出季度持仓变化（新增/清仓/增持/减持）
- **web_search**：补充资讯信息——现金仓位、最新动态、最新观点、港股披露等

## 指令：价值投资监控

**触发**："价值投资监控"、"看看巴菲特最近持仓变化"、"段永平最新动态"

### 执行步骤

#### 1. SEC 13F 季度对比

```bash
cd <SKILL_DIR> && python3 scripts/compare.py \
  --config config/watchlist.json
```

- 自动拉取 SEC 最近两期 13F（本期 vs 上期）
- 自动 diff 输出：🟢 新建仓 / 🔴 清仓 / 🔼 增持 / 🔽 减持
- 最多列出前20只持仓

#### 2. 资讯搜索（web_search）

时效限定最近7天，搜索以下关键字：

**巴菲特/伯克希尔：**
- `巴菲特 现金储备 最新`
- `伯克希尔 最新动态 观点`

**段永平：**
- `段永平 最新动态 观点`
- `段永平 港股 披露 权益变动`

每次搜索后给出一句话总结，不展示原始结果列表。

#### 3. 输出格式

**持仓列表**：按持仓比例从大到小排列，最多列出前20只，每只标注市值、占比、变化情况
**已清仓**：单独列出一节，不省略全部清仓记录

## 变化判定逻辑

- **新增**：本期有、上期无 → 🟢 新建仓
- **清仓**：上期有、本期无 → 🔴 已清仓
- **增持**：股数增加 >2% → 🔼 +X%
- **减持**：股数减少 >2% → 🔽 -X%
- **微调**：股数变动 ≤2% → 不报告

---

## 限制

- 13F 每季度申报一次，滞后约45天，非实时
- 只覆盖美股多头持仓，不含私人公司、债券、空头
- 网络资讯可能有谣言或不实传闻，需甄别
- 港股披露通过搜索获取，非直接 API
